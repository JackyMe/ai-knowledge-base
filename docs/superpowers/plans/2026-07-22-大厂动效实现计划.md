# 全站大厂动效实现计划

> **面向 AI 代理的工作者:** 必需子技能:使用 superpowers:subagent-driven-development(推荐)或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框(`- [ ]`)语法来跟踪进度。

**目标:** 为首页 `index.html` 与 9 个主题页 `topics/*.html` 引入统一的"苹果式呼吸感"动效体系——滚动浮现入场动画 + 柔和悬停反馈,范围不含搜索框/结果列表/命令面板/侧边栏等功能性 UI。

**架构:** 新增一个零依赖的 `assets/js/motion.js`(基于原生 `IntersectionObserver` 的 `[data-reveal]` 浮现控制器),配合 `assets/css/site.css` 与 `index.html` 自身 `<style>` 内新增的动效令牌(CSS 变量)及 `[data-reveal]` 基础样式。首页与 9 个主题页分别引入该脚本,在各自的入场目标元素上标记 `data-reveal`;同时把两处文件里既有的悬停态过渡曲线统一替换为呼吸曲线。

**技术栈:** 原生 CSS(自定义属性)+ 原生 JS(`IntersectionObserver`),零依赖、零构建步骤,与站点现有"技术上刻意做减法"的架构保持一致。

**依据规格:** `docs/superpowers/specs/2026-07-22-大厂动效-design.md`

## 任务 1:新建 `assets/js/motion.js`

**文件:**
- 创建:`assets/js/motion.js`

- [ ] **步骤 1:写入实现**

```js
/* AI 知识库 · 大厂动效:滚动浮现控制器(零依赖,单一职责)
   用法:给任意元素加 data-reveal 属性,首次进入视口时加 .is-visible 触发 CSS 过渡,只播放一次。
   遵守 prefers-reduced-motion:直接跳过观察,所有目标元素立即以最终态显示。 */
(function(){
  var els=document.querySelectorAll('[data-reveal]');
  if(!els.length)return;
  var reduced=matchMedia('(prefers-reduced-motion: reduce)').matches;
  if(reduced){
    els.forEach(function(el){el.classList.add('is-visible')});
    return;
  }
  var io=new IntersectionObserver(function(entries){
    entries.forEach(function(entry){
      if(entry.isIntersecting){
        entry.target.classList.add('is-visible');
        io.unobserve(entry.target);
      }
    });
  },{threshold:.15,rootMargin:'0px 0px -8% 0px'});
  els.forEach(function(el){io.observe(el)});
})();
```

**设计说明(供执行者理解,不是要写进代码的注释)**:不需要额外写"页面加载时已在视口内的元素立即播放"的特殊分支——`IntersectionObserver` 对初始化时已经在视口内的元素本来就会在下一帧立即回调 `isIntersecting:true`,天然满足"首屏元素立即浮现"的要求,且这个回调发生在浏览器完成首次布局之后,不会出现"没有过渡效果直接跳到终态"的常见坑(手动同步设置初始态容易踩这个坑,这里不需要)。
