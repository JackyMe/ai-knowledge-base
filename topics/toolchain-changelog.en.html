This page does only one thing: filters the version changes of Claude Code and Codex to "those relevant to you", clearly marking which ones will invalidate your old habits and which ones are worth trying right away.

Usage 00

How to use this page

This page is not a translation of the official changelog. Official changelogs have dozens of entries per version, mostly internal fixes, and reading them all is a waste of time. What we do here is filtering and translation: only keeping changes that affect your actual operations, and explicitly stating "what you need to change".

Meaning of the three tags

TagMeaningWhat you should do
🔴 Breaking ChangeOld syntax, commands, or configs will fail or have reversed behaviorMust-read. If something "mysteriously stops working" after an upgrade, check here first
🔄 Behavior ChangeCommands and parameters are still there, but results or timing have changedJust know about it, usually no need to change configs, but affects your expectations of the tool
🆕 New CapabilityNew commands, configs, modelsTry what's useful to you, no need to learn everything

What is not included

  • Pure internal refactoring, performance optimization (unless it affects perceptible user experience)
  • Fixes for extremely niche scenarios on specific platforms (unless it's a common trap, like Windows path issues)
  • Preview/experimental features (will be included when GA, to avoid changes right after writing)
Timeliness DeclarationClaude Code releases a version about every 1-2 days, and Codex updates weekly. If the verification date on this page is more than a month ago, you should rely on official sources, don't treat this as the sole truth. For official sources, see the How to maintain this page section.

How to maintain this page

The value of this page lies entirely in its "freshness". Left unattended, three months later it will be worse than nothing—because readers will take it as truth. Therefore, the maintenance process itself is included here.

Data sources (sorted by reliability)

ToolPrimary SourceLocal Self-check Commands
Claude Codecode.claude.com/docs/en/changelog/release-notes (to see diff from your current version to latest)
Codexlearn.chatgpt.com/docs/changelogcodex debug models (actual available models), /debug-config (why config isn't taking effect)
Don't use secondary sources as the sole basisThere are many third-party changelog aggregator sites online, updating quickly but often missing "breaking" annotations, and sometimes listing preview features as released. Anything going into the "Breaking changes" table must be verified against official sources—this rule is the difference between this knowledge base and "AI-generated collections".

Update workflow

The repository has already solidified this workflow into a reusable skill (.claude/skills/refresh-toolchain/). Just tell Claude Code to "run a toolchain version check" to trigger it. The process itself is:

  1. Confirm current date—this step cannot be skipped, otherwise it's easy to judge what's "new" based on outdated cognition
  2. Pull two official changelogs, scope is "last verification date → today"
  3. Three-category filtering: Breaking / Behavior Change / New. Internal refactors, niche platform fixes, and preview features are uniformly excluded
  4. Write back to four locations: This page's monthly archive, this page's breaking index, Claude Code guide's "Recent Important Changes", Codex guide's "Recent Important Changes"
  5. Check if old content is invalidated—this step is easiest to miss. A new version might make a description in the guide text outright wrong (e.g., command renamed, default value changed); must backtrack from changes to the main text
  6. Update date markers in three places: The top bar and hero badge of the two guides, and this page's top bar
  7. Re-run search index python3 scripts/build-search-index.py, then commit
Reminder MechanismThe repository is configured with a GitHub Action that automatically opens an issue on the 1st of every month reminding it's time to check, attached with the last check date and a link to this page. No need to memorize dates.

Note: This page is a personally curated summary of version changes, not an official release channel. The inclusion criterion is "whether it affects actual usage", thus deliberately omitting a large number of internal fixes and niche scenario changes. When any item conflicts with the official changelog, the official one prevails. If you find errors or omissions, please open an issue in the GitHub repository.
