Antigravity ガイド

デスクトップ、CLI、IDE、SDK を用途に応じて選び、権限と結果を確認します。

01

利用形態を選ぶ

プロジェクト管理はデスクトップ、端末作業は CLI、編集は IDE、プログラム連携は SDK。設定やキー操作は共通とは限りません。

www.antigravity.google · home · 2026-09-09

02

インストールとログイン

macOS/Linux は公式インストーラーを使用します。agy で認証を開始し、SSH では手元のブラウザーで認証します。実行ファイルとバージョンを確認してください。

curl -fsSL https://antigravity.google/cli/install.sh | bash
command -v agy
agy --version
agy

www.antigravity.google · install · 2026-09-09

03

CLI の基本操作

/ で利用可能なコマンドを確認します。/help、/diff、/resume、/permissions、/context、/usage が基本です。内部ツール名はシェルコマンドではありません。

www.antigravity.google · reference · 2026-09-09

04

設定と拡張

/config で CLI 設定、/mcp で接続を確認します。ルール、Skills、Hooks、プラグインの役割は異なります。各製品の設定形式に従ってください。

www.antigravity.google · settings · 2026-09-09

05

バックグラウンドと非対話実行

成果物、書き込み範囲、検証方法を指定し、/agents と /tasks で状態を確認します。スクリプトは -p を使用します。

agy -p "Summarize this repository without changing files" --output-format json

www.antigravity.google · headless · 2026-09-09

06

権限・サンドボックス・使用量

有効なサンドボックスとツール権限を確認します。既定で通信禁止とは限りません。/usage と /context は異なる制限を示します。

www.antigravity.google · permissions · 2026-09-09

07

症状から調べる

コマンド不在は PATH、認証失敗はアカウント・通信・時刻、拒否された操作は権限理由を確認します。設定を消す前に証拠を保存してください。

www.antigravity.google · troubleshooting · 2026-09-09

08

検証できる作業手順

例：認証コードを読み、変更とリスクを示し、実装後に既存テストと差分を確認します。公開、支払い、外部への送信は個別に承認を得ます。

公式資料に基づく要約です。実際の環境で検証してください。
