概要

pen.dev とは何か？

原典: pen.dev Documentation (Home)

pen.dev は 開発環境（IDE）の内部に直接統合された ベクターデザインツールです。別アプリやブラウザタブを切り替える必要なく、コードと同一のワークスペース内でデザインを直接編集できます。

なぜ pen.dev を選ぶのか？ デザインとコードを同一リポジトリに集約することで両者の乖離を解消します。キャンバス上でコンポーネントを設計し、Design Tokens をコードと同期させ、AI エージェントと連携してUI実装を爆速化します。

クイックスタート

インストール

原典: Installation

VS Code / Cursor の拡張機能パネルから導入します：

  1. エディタの拡張機能パネルで pen.dev（発行元: highagency.pencildev）を検索してインストール。
  2. ステータスバー左下の Pencil アイコン をクリックしてキャンバスを起動。
  3. 初回起動時にメールアドレスを入力してアクティベーションを完了。
クイックスタート

認証とアクティベート

原典: Authentication

入力したメールアドレス宛に届く 6 桁の確認コードを入力するだけでログインが完了します。セッション情報はローカルに安全に保存されます。

AI 統合 (MCP)

原典: AI Integration

pen.dev は Model Context Protocol (MCP) を通じて各種 AI ツール（Claude Code, Cursor, Codex, OpenCode 等）とシームレスに接続されます。

# Claude Code で MCP 接続を確認
/mcp

AI はキャンバスの要素座標や Design Tokens を直接読み取り、デザインをコードへ変換したり、自然言語から新しい画面をキャンバス上に描画したりできます。

コアコンセプト

.pen ファイル

原典: .pen Files

.pen は pen.dev のネイティブファイル形式です。中身はクリーンな JSON であり、Git でのバージョン管理、コミット差分の確認、ブランチマージに対応しています。

コアコンセプト

Design as Code（設計即コード）

原典: Design as Code

  • 単一リポジトリ管理: design.pen をソースコードと同じ Git リポジトリで管理。
  • ブランチと PR: 新機能ブランチで UI デザインと実装コードを同時に変更し、1つの PR でレビュー。
  • ロールバックの同期: git revert を行えば、コードとデザインが同時に過去の正常な状態へ巻き戻ります。
コアコンセプト

pen.dev インターフェース

原典: The Interface

  • 左側パネル (Layers / Libraries): レイヤー階層、フレーム一覧、インポートされたデザインライブラリ。
  • 中央キャンバス (Infinite Canvas): ベクター編集を行う無限キャンバス領域。
  • 右側パネル (Inspector): 選択中ノードのプロパティ（位置、サイズ、塗り、線、角丸、エフェクト、変数バインド）。
コアコンセプト

変数 (Variables / Design Tokens)

原典: Variables

カラー、数値（余白や角丸）、文字列を Design Tokens として定義し、各要素に $color.primary のように紐付けます。トークンの値を1箇所変更するだけで、キャンバス全体および CSS コードに即座に反映されます。

コアコンセプト

コンポーネント (Components)

原典: Components

再利用可能な UI 要素を定義します。マスターコンポーネントを変更すると、すべてのインスタンス（参照ノード）に変更が伝播します。

コアコンセプト

スロット (Slots)

原典: Slots

コンポーネント内の特定領域を動的に差し替え可能にするプレースホルダーです。モーダルダイアログの本文領域や、カードコンポーネントのメディア領域などに活用します。

キャンバス上のコード (Code on Canvas / Script Nodes)

原典: Code on Canvas

JavaScript / TypeScript スクリプトを用いて、データドリブンなグラフや複雑な幾何学パターンをキャンバス上にプログラムから直接描画できます。

.lib.pen 形式で保存された共通のデザインシステムを複数プロジェクト間で共有・インポートできます。

pen.dev インポート/エクスポート

原典: Core Concepts / Import & Export

インポート (Import)

ソースインポート方法
完全な Figma ファイルツールバー：Rectangle アイコン下の矢印をクリック → Import Figma。デスクトップアプリ：File → Import Image/SVG/Figma...
単一の Figma レイヤーFigma で要素をコピーし、pen.dev キャンバスに直接ペースト（⚠️ 画像要素はコピペ非対応：完全なファイルをインポートするか手動で画像を追加）
画像ドラッグ＆ドロップ ／ コピー＆ペースト ／ ツールバーの Import Image or SVG... ／ デスクトップアプリの File メニュー。PNG、JPEG、SVG に対応
アイコン組み込みアイコンライブラリ：Material Symbols（Outlined/Rounded/Sharp）、Lucide、Feather、Phosphor。独自の SVG アイコンも画像同様にインポート可能

エクスポート (Export)

  • デザインからコード生成：Cmd/Ctrl + K で AI チャットを開き、デザインに基づくコード生成を指示します。
  • 単一要素のエクスポート：要素を選択 → プロパティパネル下部でサイズと形式（PNG / JPEG / WEBP / PDF）を選択 → Export layer をクリックして保存先を選択します。

デザイン & コード

デザイン ↔ コード同期

原典: Design to Code

キャンバスのノード構造から Tailwind CSS, React, Vue, HTML/CSS コンポーネントを即座に出力。逆に、既存のソースコードを読み込んでキャンバス上にビジュアルとして復元することも可能です。

トラブルシューティング

トラブルシューティング

原典: Troubleshooting

  • MCP が接続されない: claude の CLI ログイン状態を確認し、エディタを再起動。
  • キャンバスが表示されない: VS Code の GPU アクセラレーション設定を確認。
  • 変更が消えた: 現行バージョンでは自動保存がないため、必ず Cmd/Ctrl + S で明示的に保存してください。

pen.dev CLI & MCP ツール体系

原典: pen.dev CLI

CLI（@pen.dev/cli）を利用したヘッドレス実行と、AI エージェントが呼び出す MCP ツール群：

MCP ツール名機能概要
executeノードの追加・更新・削除・移動・置換、変数の読み書き（GetVariables / SetVariables）
get_app_stateドキュメント全体の構造・メタデータを取得
get_screenshot指定ノードを PNG 画像としてレンダリング取得
export_nodesノードを PNG / JPEG / WebP / PDF 等でエクスポート
get_guidelinesデザインガイドラインとスタイル規約を取得
