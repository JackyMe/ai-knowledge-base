CORE 02

Six-Element Prompt Framework

Professional image prompting is not about stuffing arbitrary keywords; it demands a structured "Six-Element Framework". Direct the model like an Art Director instructing a production crew:

① Subject Detailed depiction of the focal character/object: age, clothing, expressions, posture
② Action What the subject is actively doing; dynamic poses, gestures, and behavioral state
③ Environment Setting, time of day, weather, season, physical location, background depth
④ Style Art movement or medium: watercolor, 3D render, minimalist vector, oil painting
⑤ Technical Optics, lighting setup, camera angle, framing, focal length, lens parameters
⑥ Vibe Emotional undertone: nostalgic, epic, serene, tense, cozy, ethereal

From Simple to Production: 4-Level Progression

Lv1 Minimal A cat sitting.
→ Result: Generic, unremarkable, default AI look.
Lv2 Add Environment A cat sitting on a wooden windowsill looking outside.
→ Result: Establishes context, but visual style remains random.
Lv3 Add Style & Lighting A photorealistic image of a fluffy white cat sitting on a wooden windowsill looking at the sunset, warm sunlight casting long shadows.
→ Result: Evokes emotion, depth, and aesthetic polish.
Lv4 Technical / Production (Recommended) A professional editorial photograph of a fluffy white cat sitting on a wooden windowsill looking at the sunset, warm golden hour light, shot on 35mm lens, shallow depth of field, high-resolution, cinematic composition.
→ Result: Commercial studio grade, production-ready.
💡 Core Prompting Principles
  • Use Natural Narrative Prose: Unlike Midjourney's comma-separated tag soup, ChatGPT excels when given structured, coherent prose.
  • Restraint & Focus: Maintain 5–7 core descriptive anchors to prevent prompt bloat and "feature leakage".
  • Positive Affirmation Over Negation: Never say "no glasses"; specify "clear, unobscured eyes with natural facial expression".
  • English for Technical Descriptors: Even if framing subjects in another language, use English for technical terms like 85mm lens, f/1.8, Unreal Engine 5.

Handling Negative Prompts Effectively

ChatGPT lacks a native negative prompt field and struggles with negation phrases like "don't" or "no" (it tends to render whatever concepts you mention). Here is the proven solution:

❌ Ineffective (Negative Instructions) "Don't include glasses"
"no cartoon style"
"no cluttered background"
→ Model often hallucinates glasses, cartoon artifacts, or busy backgrounds.
✅ Effective (Positive Framing) "Clear, unobscured eyes and natural face"
"highly detailed photorealistic skin texture"
"isolated on solid seamless white background, nothing else"

Reverse Engineering Prompts with GPT

  1. Upload Reference Image: Upload an image with the exact aesthetic, lighting, or composition you admire.
  2. Ask GPT for Deconstruction: Instruct: "Analyze the composition, lighting, materials, color palette, and art style of this image. Reverse-engineer an optimal English image prompt to reproduce this exact aesthetic."
  3. Direct Generation: Command GPT to generate a new image utilizing the synthesized prompt—this produces ten times higher fidelity than simply saying "draw something like this".

Chain-of-Thought Image Prompting

🧠 Chain of Thought Prompt Before generating the image, write three short paragraphs analyzing the composition, color psychology, and metaphorical visual elements for [topic]. Once analyzed, synthesize your findings into an optimal image prompt and render the image.

Multilingual Prompting Strategy

💡 Mixed-Language Strategy (Best Practice) Narrative subjects and cultural context can be specified in any native language, but keep photographic terms, art styles, and technical parameters in English (e.g., 85mm lens, f/1.8, isometric, Unreal Engine 5) for maximum fidelity and accurate token matching.

CORE 05

Typography & Text Rendering Strategy

Text rendering was historically the greatest limitation of AI image generation. The native multimodal architecture of GPT-4o has fundamentally solved this challenge:

Core Rules for Precision Text Rendering

  • Double Quotation Marks: Encapsulate the exact text inside double quotes: A neon sign that reads "OPEN 24 HOURS"
  • Spatial Anchoring: Explicitly specify where the text lives—"printed across the ceramic mug", "on the storefront window", "centered on the whiteboard".
  • Brevity is King: 1–4 words yield the highest success rate; lengthy paragraphs dramatically increase error probability.
  • Typographic Styling: Describe the font style in English: bold sans-serif, elegant cursive, 3D bubble letters.
  • In-Place Iterative Correction: If a typo occurs, never regenerate from scratch! Instruct: "Keep the entire image identical, only change the sign text to 'HELLO'".

Multilingual Text Rendering (CJK & More)

🌐 2025–2026 Multilingual Breakthrough Modern GPT image models render CJK (Chinese, Japanese, Korean) and Arabic characters with unprecedented fidelity. Specify your exact characters in quotes: A neon sign that reads "你好未来" or "未来への扉", and the model embeds it naturally into poster typography or calligraphy.

→ AI lacks mathematical precision; numbers, axes, and proportions will be distorted.

Artistic Backdrops: Generate clean negative-space templates with AI, then overlay real data in Figma or Canva.
PRACTICE 06

Image Editing & Iteration Workflows

Three Primary Image Editing Workflows

  1. Inpainting (Selective Repainting): Click the image to enter edit mode → brush over the target region → enter modification instructions (e.g., "change this shirt to red stripes"). The AI preserves surrounding context and lighting.
  2. Comment-Driven Annotations (Images 2.5): Circle any region directly on the canvas and attach text feedback → the model interprets localized intent without disturbing other elements.
  3. Global Semantic Transfer: Upload an image → specify a target aesthetic ("convert to cyberpunk anime"). Note that this is semantic re-synthesis, not a simple color filter.

Multi-Turn Conversational Iteration Best Practices

🔄Progressive Micro-Tuning WorkflowITERATIVE
  1. Initial Draft: "Generate a girl reading a book in an ancient forest."
  2. Adjust Environment: "Keep composition identical, shift time to midnight with glowing fireflies."
  3. Swap Props: "Keep character unchanged, replace her book with a glowing laptop."
  4. Localized Inpainting: Notice deformed fingers? Inpaint brush → "Fix hand anatomy to show exactly 5 well-formed fingers."
⚠️ Pitfalls in Conversational Iteration
  • If an iteration fails 3 times consecutively, the chat context becomes polluted. Open a fresh chat using the best-refined prompt.
  • When making incremental modifications, always emphasize "Keep [X, Y, Z] completely unchanged" to prevent compositional drift.
  • Save prompts, references, and outputs for comparison; do not ask for invented seeds.

Transparent Background Workflows

ChatGPT's native image model does not directly export PNGs with an alpha channel. Here is the standard production pipeline:

  1. Solid Backdrop Prompt: Request solid seamless white background or chroma key green background, no shadows.
  2. Python Background Removal: Ask ChatGPT Code Interpreter to execute Python (rembg or PIL thresholding) to export a transparent PNG.
  3. External Tooling: Alternatively, use Remove.bg, Canva, or macOS Preview / iOS one-tap cutout for instant separation.

Character and style consistency

Choose a reference and specify preserved face, clothing, colors, and composition. Compare each edit against it. Do not ask the model to invent seeds or gen_ids; saying “same seed” does not guarantee reproducibility.

Practical control techniques

Save references, prompts, and iterations. Define preserved elements and edit regions; use sketches for composition. Do not rely on undocumented seeds, rights-bypass tricks, or pixel-perfect promises. Typeset critical text deterministically.

Compare tools on the same task

Compare tools using identical references, text, and constraints. Measure text errors, edit drift, consistency, latency, and cost. Record versions and outputs instead of universal rankings. Review licenses separately.

Check before delivery

Verify text, numbers, and charts. Check permissions for people, brands, and assets, and whether sensitive material can be uploaded or shared. Successful generation does not establish usage rights.
