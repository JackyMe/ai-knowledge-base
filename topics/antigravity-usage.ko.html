Antigravity 사용 가이드

작업에 맞는 데스크톱, CLI, IDE, SDK를 선택하고 권한과 결과를 확인하세요。

01

사용 환경 선택

프로젝트 관리는 데스크톱, 터미널 작업은 CLI, 편집은 IDE, 프로그램 연동은 SDK를 사용합니다. 설정과 단축키는 다를 수 있습니다.

www.antigravity.google · home · 2026-09-09

02

설치 및 로그인

macOS/Linux에서는 공식 설치 프로그램을 사용합니다. agy로 인증을 시작하고 SSH에서는 로컬 브라우저로 인증합니다. 실행 파일과 버전을 확인하세요.

curl -fsSL https://antigravity.google/cli/install.sh | bash
command -v agy
agy --version
agy

www.antigravity.google · install · 2026-09-09

03

CLI 기본 사용법

/로 사용 가능한 명령을 확인하세요. /help, /diff, /resume, /permissions, /context, /usage가 기본입니다. 내부 도구 이름은 셸 하위 명령이 아닙니다.

www.antigravity.google · reference · 2026-09-09

04

설정 및 확장

/config로 CLI 설정을, /mcp로 연결을 확인합니다. 규칙, Skills, Hooks, 플러그인의 역할은 다릅니다. 각 제품의 설정 형식을 따르세요.

www.antigravity.google · settings · 2026-09-09

05

백그라운드 및 비대화형 실행

산출물, 쓰기 범위, 검증 방법을 지정하고 /agents 및 /tasks로 상태를 확인합니다. 스크립트에서는 -p를 사용하세요.

agy -p "Summarize this repository without changing files" --output-format json

www.antigravity.google · headless · 2026-09-09

06

권한, 샌드박스 및 사용량

활성 샌드박스와 도구 권한을 확인하세요. 기본적으로 네트워크가 차단된다고 가정하지 마세요. /usage와 /context는 서로 다른 제한을 나타냅니다.

www.antigravity.google · permissions · 2026-09-09

07

증상별 문제 해결

명령이 없으면 PATH를, 로그인 오류는 계정·네트워크·시간을, 도구 거부는 권한 사유를 확인합니다. 설정을 지우기 전에 증거를 보존하세요.

www.antigravity.google · troubleshooting · 2026-09-09

08

검증 가능한 작업 흐름

예: 인증 코드를 읽고 변경 사항과 위험을 정리한 뒤 구현하고 기존 테스트와 diff를 확인합니다. 게시, 결제, 외부 메시지는 별도 승인을 받습니다.

공식 자료를 바탕으로 정리했습니다. 실제 환경에서 예제를 검증하세요.
