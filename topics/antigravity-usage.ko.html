핵심 기반 01

1️⃣ Antigravity 핵심 개념과 멘탈 모델

공식 기준 정합 Google Antigravity (코드명 AGY)는 Google이 Agentic AI 소프트웨어 엔지니어링 시대를 위해 구축한 차세대 풀스택 기반입니다. 단순한 대화형 코드 완성을 넘어 OS 수준 샌드박스, 다중 에이전트 협업 오케스트레이션, MCP (Modular Command Protocol) 프로토콜, AST 코드 레벨 의미론적 인지 및 컨텍스트 수명주기 관리를 하나로 융합했습니다.

Antigravity 6대 핵심 아키텍처 개념

  • agy CLI: 통합 명령줄 진입점. 워크스페이스 진단, 코드 검색, 수정 제안 및 서브에이전트 디스패치를 주도합니다.
  • Agentic IDE: 2열 구조로 매끄럽게 융합된 그래픽 IDE. 코드 에디터, Planning Mode 계획 검토 패널, 실시간 Diff 트래커, Artifacts 비주얼 뷰어를 기본 내장합니다.
  • Customizations 커스터마이징 체계: 프로젝트 내 .agents/ 또는 전역 ~/.gemini/antigravity/ 기반의 계층형 확장 센터로 Skills(스킬), Rules(규칙), Plugins(플러그인), MCP 서버를 포함합니다.
  • Subagents 에이전트 네트워크: 독립적인 Conversation ID, 컨텍스트 상태 머신 및 워크스페이스 격리 모드를 갖춘 자율 백그라운드 에이전트로 부모-자식 간 유기적 통신을 지원합니다.
  • Artifacts 산출물 메커니즘: 복잡한 아키텍처 설계, 다이어그램(Mermaid), UI 프로토타입, 마이그레이션 계획을 표준 Markdown으로 영속화하여 대화창 스크롤 오염을 방지합니다.
  • Reactive Wakeup (반응형 깨우기): 완전 비동기 태스크 아키텍처로, 메인 에이전트가 백그라운드 작업이나 스케줄러를 등록한 후 반복 폴링(Polling)할 필요 없이 완료 시 시스템이 자동으로 메인 에이전트를 깨웁니다.

Antigravity Agentic IDE 단축키 매트릭스

  • Cmd+L / Ctrl+L —— 우측 Agent 인터랙션 패널에 포커스하고, 현재 선택된 코드 줄과 파일 앵커를 프롬프트에 자동 주입합니다.
  • Cmd+Shift+P —— Antigravity 커맨드 팔레트를 열어 /goal, /schedule, /grill-me 등 고급 워크플로우를 신속 실행합니다.
  • Ctrl+Alt+R —— 샌드박스 내에서 현재 파일 또는 관련 테스트 스위트를 자동 실행하여 패스 증빙을 출력합니다.
  • Ctrl+Alt+S —— 현재 세션에서 생성된 Markdown / HTML / UI Artifacts를 실시간 화면 분할로 렌더링합니다.
확장 체계 04

4️⃣ Customizations 커스터마이징 체계: Skills · Rules · MCP · Plugins

Antigravity는 3단계 우선순위 규칙 탐색 시스템을 갖추고 있습니다: 현재 프로젝트 .agents/ (최우선) > 사용자 전역 ~/.gemini/antigravity/ > 내장 기본값 (Built-in). 모든 규칙은 재시작 없이 핫 리로드(Hot-reload)를 지원합니다.

4.1 고가용성 Skill 작성 (보안 감사 Skill 예시)

.agents/skills/security-guard/SKILL.md 파일에 기능 및 규칙을 선언합니다:

---
name: security-guard
description: "프로덕션급 민감 정보 및 SQL 인젝션 정적 보안 감사 스캐너"
---
# 핵심 보안 감사 준칙
1. 코드 내에 API Key, JWT Secret, 사내 데이터베이스 비밀번호를 하드코딩하는 행위를 엄격히 금지합니다.
2. 외부에 노출되는 모든 API 요청 파라미터는 엄격한 스키마 검증과 역직렬화 제약을 거쳐야 합니다.
3. 모든 데이터베이스 쿼리를 검사하고, 파라미터화된 프리페어드 스테이트먼트(Prepared Statement) 바인딩을 강제하여 문자열 연결 기반 SQL 생성을 완전히 차단합니다.
4. 외부 HTTP 요청은 반드시 타임아웃(Timeout) 설정과 지수 백오프 재시도(Exponential Backoff)를 강제 구성해야 합니다.

4.2 전역 가로채기 규칙 (Rules) 작성

# .agents/rules/safe-terminal.yml
---
severity: critical
description: "샌드박스 방어: 미승인 민감 파일 유출 및 고위험 터미널 명령어 차단"
enforce:
  - tool: run_command
    condition: "BypassSandbox == false && CommandLine matches '(rm\\s+-rf\\s+/|mkfs|dd\\s+if=)' => reject"
  - tool: replace_file_content
    condition: "TargetFile matches '\\.(env|pem|key)$' => require_user_approval"

엔지니어링 거버넌스 07

7️⃣ 성능, 비용과 샌드박스 보안 방어 체계

  1. 표준 샌드박스 우선 원칙 (Standard Sandbox First): 모든 터미널 명령어는 기본적으로 외부 네트워크가 차단되고 파일시스템이 제한된 표준 샌드박스에서 실행됩니다. 종속성 다운로드나 외부 네트워크 통신이 명백히 필요한 경우에만 BypassSandbox: true를 선언하고 사용자의 명시적 승인을 거칩니다.
  2. Planning Mode 규율: 멀티 파일 아키텍처 개편이나 모듈 간 리팩토링이 필요한 복잡한 작업은 반드시 먼저 implementation_plan.md 설계안을 생성하여 사용자의 검토 사항과 자체 검증 단계를 명시해야 하며, 승인 전 소스코드의 무단 수정을 엄격히 금지합니다.
  3. 증분 정밀 패치 (Incremental Edits): 수천 줄에 달하는 대용량 파일에서 전체 덮어쓰기를 절대 지양하고 replace_file_content를 활용한 정밀 위치 수정을 적용하여 컨텍스트 Token을 대폭 절약하고 깔끔한 Git 이력을 유지합니다.
엔지니어링 거버넌스 08

8️⃣ 함정 체크리스트 & 30초 응급실

대표적 오류 및 증상근본 원인30초 자가 해결 가이드
TargetContent not found대상 코드 블록의 들여쓰기, 줄바꿈 문자(CRLF vs LF), 보이지 않는 공백 문자가 파일과 불일치먼저 view_file로 대상 라인 번호와 들여쓰기를 정밀 확인한 후 TargetContent에 그대로 전달합니다.
Subagent in waiting_for_input서브에이전트가 사용자 확인이 필요한 명령어 프롬프트에 도달함manage_subagents list로 상태를 확인한 후 send_message로 확인 명령을 전송하면 즉시 재개됩니다.
Sandbox Network Blocked표준 샌드박스 내에서 curl, npm install, git pull 등을 실행함네트워크 보안성 확인 후 매개변수에서 BypassSandbox: true를 지정하여 권한 승격을 요청합니다.
Context Token Overflow단일 세션 내에서 초대형 로그나 초거대 JSON을 연속 출력함/clear로 과거 이력을 정리하거나, 대용량 로그 처리를 research 서브에이전트에 위임합니다.
