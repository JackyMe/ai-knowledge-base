Google AI エコシステム

用途に応じて Gemini API、NotebookLM、Canvas、Antigravity を選び、制限と検証方法も確認します。

01

用途でツールを選ぶ

API 連携は Gemini API、資料の読解は NotebookLM、試作は Canvas、コード作業は Antigravity。まず一つで始め、必要な連携だけ追加します。

02

API とモデル選択

モデル ID、コンテキスト長、地域、割当量は利用先で確認します。一律 2M とは限りません。例の実行前に API キーとモデル ID を設定してください。

import os
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
response = client.models.generate_content(
    model=os.environ["GEMINI_MODEL"],
    contents="Summarize the supplied requirements and list open questions.",
)
print(response.text)

03

キャッシュと総費用

Interactions は暗黙キャッシュに対応し、明示キャッシュは GenerateContent を使います。キャッシュ名は model ではなく専用フィールドに渡します。総費用で効果を評価してください。

04

構造化出力と検証

対応する JSON Schema を指定し、値と業務規則を検証します。JSON の形式が正しくても事実は誤り得ます。拒否、切り詰め、空の結果、通信失敗も処理します。

05

NotebookLM：引用と検証

関連資料をまとめ、明確な質問をします。引用箇所、日付、適用条件を確認してください。引用があっても正確とは限らず、資料や生成回数には制限があります。

support.google.com · notebooklm · 2026-09-09

06

検索しやすい資料の準備

見出し、出典、版、コードのパスを残します。依存物、ビルド結果、重複、認証情報は除外し、形式とデータ方針、OCR を確認します。

07

音声概要と学習

音声概要は導入として使い、原文の代わりにはしません。対象と範囲を指定し、名称、数値、発言の帰属を原文で確認します。
