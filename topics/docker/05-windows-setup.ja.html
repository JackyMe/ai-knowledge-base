05. Windows環境の落とし穴回避ガイド

主要なデスクトップOSの中で、歴史的に最もDocker導入のハードルが高かったのがWindowsです。Dockerのコア機能はLinuxカーネルに依存しており、Windowsにはそれがネイティブに存在しなかったためです。

かつては動作が重く、ブルースクリーンに悩まされることもありました。しかし現在、Microsoftが導入したWSL2（Windows Subsystem for Linux 2）という革新的なアーキテクチャにより、Windows上で本物の最適化されたLinuxカーネルを直接動かせるようになり、ネイティブLinux並みに快適にDockerが動くようになりました。

本レッスンでは、よくある落とし穴を回避しながら、確実にWindows環境へDockerを構築する手順をステップバイステップで解説します。

🚨
事前ヘルスチェック：PCの準備はできていますか？

1. OSバージョン：Windows 10（64bit バージョン2004 / ビルド19041以上）または Windows 11 が必須です。Windows 7などの古いOSの場合は先にOSを更新してください。
2. ハードウェア仮想化支援機能：マザーボードのBIOSでCPUの仮想化支援機能（Intel VT-x / AMD-V）が「有効（Enabled）」になっている必要があります。Ctrl+Shift+Esc でタスクマネージャーを開き →「パフォーマンス」タブ → 右下の「仮想化」が「有効」になっているか確認してください。「無効」の場合はPC再起動時にBIOS画面に入り有効化してください。

ステップ1：カーネルの基盤 — WSL2 のインストール

いきなり Docker Desktop をインストールしてはいけません。まずは土台を整えます。PowerShell または コマンドプロンプト（CMD）を「管理者として実行」で開き、以下のコマンドを実行します。

wsl --install

Windowsが必要な仮想マシンプラットフォームコンポーネントを自動で有効化し、標準の軽量Ubuntu Linuxディストリビューションをダウンロードします。処理が完了したら、必ずPCを再起動してください！

再起動後、スタートメニューから新しく追加された Ubuntu アプリを起動し、初期ユーザー名とパスワードを設定すれば、基盤の準備は完了です。

ステップ2：Docker Desktop のインストール

  1. Docker 公式サイト（docker.com）にアクセスし、Docker Desktop for Windows をダウンロードします。
  2. インストーラーをダブルクリックして実行します。インストール中に出てくる Use WSL 2 instead of Hyper-V (recommended) というチェックボックスには必ずチェックを入れてください！ これにより最高のパフォーマンスと最小のオーバーヘッドで動作します。
  3. 「Next」をクリックしてインストールを完了します。デスクトップにクジラのアイコンが作成されます。
  4. Docker Desktop を起動します。タスクバーの通知領域にあるクジラアイコンが初期化中にオレンジ色で点滅し、緑色の点灯（または静止状態）になれば、Docker Engineの起動成功です！

ステップ3：インストールの検証

正常に動作しているか確認しましょう。PowerShell または CMD を開き、以下を実行します。

# クライアントとデーモンのバージョンを確認（情報が返ってくれば通信成功）
docker version

# 公式の検証用コンテナを実行
docker run hello-world

ターミナルに "Hello from Docker! This message shows that your installation appears to be working correctly." というメッセージが表示されれば成功です！ Windows環境でのセットアップの壁を無事に突破しました。

🚀 プロの知恵：WSL2によるメモリとCドライブの圧迫を防ぐ設定

デフォルト状態の Docker Desktop と WSL2 は、ホストの空きメモリを動的に無制限に確保しようとし、イメージファイルもCドライブに保存します。

対策：Windowsのユーザーディレクトリ（C:\Users\<ユーザー名>）直下に、.wslconfig という名前のファイルを作成します（先頭のドットを忘れずに）。以下の設定を記述してリソース消費に上限を設けます。

[wsl2]
memory=4GB   # WSL2の最大メモリ消費量を4GBに制限
processors=2 # 使用CPUコア数を2つに制限

ファイルを保存後、PowerShell で wsl --shutdown を実行してWSLサブシステムを再起動すれば、制限が適用されます。

⚠️ Windows トラブル救護室
Q1: Docker Desktop で "WSL 2 installation is incomplete." とエラーが出る
A: WSL2機能は有効化されているものの、Linuxカーネル更新パッケージが不足しています。エラーダイアログのリンクから Microsoft 公式の wsl_update_x64.msi をダウンロードしてインストールし、Docker Desktop を再起動してください。
Q2: "Hardware assisted virtualization and data execution protection must be enabled in the BIOS" とエラーが出る
A: 本レッスンの冒頭のアラートを確認してください！ マザーボードのBIOSでCPU仮想化支援機能（VT-x / AMD-V）が無効になっています。お使いのPC/マザーボードのメーカー名＋「BIOS 仮想化 有効」で検索し、BIOS設定画面から有効化してください。
Q3: CMDで docker と入力すると「'docker' は内部コマンドまたは外部コマンドとして認識されていません」と出る
A: インストーラーによるシステム環境変数の追加が失敗している可能性があります。Windowsの「システムの詳細設定」→「環境変数」を開き、システム環境変数 PATH に C:\Program Files\Docker\Docker\resources\bin を手動で追加してターミナルを再起動してください。
