05. Windows 玩家避坑指南

在所有操作系统的安装中，Windows 是坑最多、水最深的一个。因为 Docker 的底层严重依赖 Linux 的系统内核，而 Windows 天生是没有这个东西的。

在早些年，Windows 上的 Docker 慢得像蜗牛，还会经常死机蓝屏。但现在，微软推出了 WSL2 (Windows Subsystem for Linux 2) 架构，堪称神来之笔。它直接在 Windows 系统里原生内嵌了一个真实的 Linux 内核，让 Docker 在 Windows 上跑得和在纯 Linux 服务器上一样丝滑。

本指南将手把手带你避开所有暗雷，完美装上 Docker。

🚨
课前体检：你的电脑达标了吗？

1. 系统版本：必须是 Windows 10 或 Windows 11。如果是 Win7，请出门右转重装系统。
2. 硬件支持：必须在 BIOS 里开启 CPU 虚拟化 (Virtualization Technology)。按 Ctrl+Shift+Esc 打开任务管理器 -> 选择“性能” -> 看看右下角的“虚拟化”是否显示为“已启用”。如果显示“已禁用”，你需要重启电脑狂按 F2/Del 进入主板 BIOS 开启它，否则神仙难救。

步骤一：安装内核基石 —— WSL2

不要急着去下载 Docker，我们得先把地基打好。打开以管理员身份运行的 PowerShell 或者命令提示符 (CMD)，输入这行魔法命令：

wsl --install

系统会自动开启相关功能，并默认下载一套轻量级的 Ubuntu Linux。安装完成后，必须重启电脑！必须重启电脑！必须重启电脑！

重启后，如果你在开始菜单里看到了 Ubuntu 的图标，点开它，设置一个普通的 Linux 账号密码（瞎敲一个自己能记住的就行），这一步就圆满完成了。

步骤二：请主角登场 —— 安装 Docker Desktop

  1. 去 Docker 官网 (docker.com) 下载 Docker Desktop for Windows 安装包。
  2. 双击运行，这期间会弹出一个极其关键的界面，其中有一项：Use WSL 2 instead of Hyper-V (recommended)。务必勾选它！这决定了你能否拥有极速的体验。
  3. 一直点 Next，安装完成后，桌面上会出现一只顶着集装箱的小鲸鱼图标。
  4. 双击启动它。右下角任务栏里的鲸鱼图标会先处于闪烁或橙色状态（代表正在启动），最终变成绿色或静止，表示 Engine running，大功告成！

步骤三：验明正身

到底装好没有？打开你的终端（PowerShell 或 CMD），敲下以下命令：

# 检查客户端和服务端版本，能输出一大串版本号说明前后端连通了
docker version

# 跑一个官方验证镜像
docker run hello-world

如果你在屏幕上看到了一段洋溢着热情的英文 "Hello from Docker! This message shows that your installation appears to be working correctly."，恭喜你，通关成功！

🚀 老鸟技巧 (Pro-Tip)：拯救被吃光的 C 盘

Docker 默认会把拉下来的镜像文件全部塞在 C 盘。时间一长，几十 G 就没了。这谁顶得住？

解决方案：在系统用户目录 (C:\Users\你的用户名) 下新建一个名为 .wslconfig 的文件（注意前面有个点）。在里面写入以下内容，用来限制 WSL2 无底洞式的吃内存，并限制它最大使用的核心数：

[wsl2]
memory=4GB   # 限制最大使用 4G 内存
processors=2 # 限制最多使用 2 个 CPU 核心

保存后，在终端执行 wsl --shutdown 彻底重启 WSL 服务生效。

⚠️ 绝望的 Windows 踩坑自救室
Q1: 启动 Docker Desktop 弹窗报错 "WSL 2 installation is incomplete." 怎么办？
A: 微软的锅。你的 WSL2 虽然开启了，但内核没有更新到最新。点击报错弹窗里的官方链接，下载 `wsl_update_x64.msi` 安装包，双击装一下，然后重启 Docker 即可。
Q2: 报错 "Hardware assisted virtualization and data execution protection must be enabled in the BIOS"
A: 回去仔细看本章开头的红色警告！你的主板 BIOS 没有开启虚拟化支持（VT-x/AMD-V），去百度搜“你的电脑品牌 + 如何在BIOS开启虚拟化”跟着做。
Q3: 为什么我在 CMD 里输入 docker 提示“不是内部或外部命令”？
A: 安装程序在配置系统环境变量时翻车了。你需要手动把 `C:\Program Files\Docker\Docker\resources\bin` 加入到你的 Windows 系统的 PATH 环境变量中，然后重启终端。
