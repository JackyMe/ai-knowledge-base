05. Windows 사용자를 위한 함정 탈출 가이드

모든 운영체제 중 Docker 설치 시 가장 많은 함정과 시행착오가 발생하는 환경이 바로 Windows입니다. Docker의 근본적인 동작 메커니즘이 Linux 커널에 깊이 의존하지만, Windows는 구조적으로 Linux 커널을 내장하고 있지 않기 때문입니다.

과거에는 Windows 환경에서 가상 머신(VirtualBox)을 띄워 Docker를 구동하느라 속도가 달팽이처럼 느리고 블루스크린이 자주 발생했습니다. 그러나 마이크로소프트가 WSL2 (Windows Subsystem for Linux 2)를 도입하면서 상황이 완전히 달라졌습니다. Windows 시스템 내부에 실제 경량 Linux 커널을 네이티브로 탑재하여, 순수 Linux 서버 못지않은 쾌적한 속도로 Docker를 구동할 수 있게 되었습니다.

본 가이드에서는 설치 중 맞닥뜨릴 수 있는 모든 장애물을 피해 완벽하게 Docker를 세팅하는 방법을 안내합니다.

🚨
설치 전 필수 점검 사항

1. OS 버전: 반드시 Windows 10(버전 2004 이상) 또는 Windows 11이어야 합니다. Windows 7/8은 지원되지 않습니다.
2. CPU 가상화 활성화: 메인보드 BIOS에서 CPU 가상화 기술(VT-x / AMD-V)이 활성화되어 있어야 합니다. Ctrl + Shift + Esc로 작업 관리자를 열고 [성능] 탭에서 우측 하단의 "가상화" 항목이 "사용"으로 되어 있는지 확인하세요. 만약 "사용 안 함"이라면 PC 재부팅 시 F2 또는 Del 키를 눌러 BIOS 설정에서 가상화를 켜야 합니다.

1단계: 핵심 기반 엔진인 WSL2 설치하기

Docker 설치에 앞서 기반 토대인 WSL2를 먼저 구축해야 합니다. 관리자 권한으로 PowerShell 또는 명령 프롬프트(CMD)를 실행한 뒤 다음 명령어를 입력합니다.

wsl --install

명령어를 실행하면 Windows 가상 머신 플랫폼 및 WSL 필수 구성 요소가 활성화되며, 기본 배포판으로 Ubuntu Linux가 자동으로 다운로드됩니다. 설치가 완료된 후 반드시 PC를 재부팅해야 합니다!

재부팅 후 시작 메뉴에 Ubuntu 아이콘이 나타나면 이를 클릭하여 터미널 창을 엽니다. 사용할 Linux 사용자 이름과 비밀번호를 설정하면(간단하게 기억할 수 있는 값으로 입력) 기본 준비가 완료됩니다.

2단계: Docker Desktop for Windows 설치하기

  1. Docker 공식 웹사이트(docker.com)에서 Docker Desktop for Windows 설치 패키지(Installer)를 다운로드합니다.
  2. 설치 파일을 더블 클릭하여 실행합니다. 설치 마법사 진행 중 나타나는 옵션 화면에서 Use WSL 2 instead of Hyper-V (recommended) 항목을 반드시 체크합니다. 이 옵션이 고성능 WSL2 기반 구동을 결정짓는 핵심 설정입니다.
  3. 설치가 완료되면 바탕화면에 고래 모양의 Docker Desktop 아이콘이 생성됩니다.
  4. 앱을 실행하면 작업 표시줄 우측 트레이의 고래 아이콘이 깜빡거리며 초기화를 진행하고, 잠시 후 녹색(Engine running)으로 안정화되면 정상 구동된 것입니다.

3단계: 정상 설치 여부 최종 검증

정상적으로 연동되었는지 확인하기 위해 PowerShell 또는 명령 프롬프트(CMD)를 열고 다음 명령어를 실행합니다.

# 클라이언트 및 서버 버전 출력 확인 (통신 성공 여부 판별)
docker version

# 공식 헬로월드 테스트 컨테이너 실행
docker run hello-world

터미널에 "Hello from Docker! This message shows that your installation appears to be working correctly."라는 메시지가 출력된다면 완벽하게 성공한 것입니다!

🚀 실무 팁: C 드라이브 용량 고갈 방지 및 메모리 제한 설정

Docker는 기본적으로 다운로드한 이미지와 컨테이너 레이어를 C 드라이브의 가상 디스크(ext4.vhdx)에 저장합니다. 방치하면 수십 GB를 차지하여 디스크가 꽉 찰 수 있습니다.

해결책: 사용자 홈 디렉터리(C:\Users\사용자이름)에 .wslconfig 파일을 생성하고(파일명 맨 앞 점에 주의), 다음 내용을 작성하여 WSL2가 과도하게 호스트 RAM을 점유하지 않도록 제한합니다.

[wsl2]
memory=4GB   # WSL2의 최대 메모리 사용량을 4GB로 제한
processors=2 # 최대 CPU 코어 사용량을 2개로 제한

저장 후 PowerShell에서 wsl --shutdown 명령을 실행하여 WSL 백그라운드 서비스를 완전히 재시작하면 설정이 즉시 반영됩니다.

⚠️ Windows 트러블슈팅 구조대
Q1: Docker Desktop 실행 시 "WSL 2 installation is incomplete." 팝업 에러가 뜹니다.
A: WSL2 기능은 켜졌으나 커널 업데이트 패키지가 누락된 경우입니다. 에러 팝업 내의 공식 다운로드 링크를 클릭하거나 마이크로소프트 공식 사이트에서 wsl_update_x64.msi 패키지를 받아 설치한 후 재부팅하면 해결됩니다.
Q2: "Hardware assisted virtualization and data execution protection must be enabled in the BIOS" 에러가 발생합니다.
A: 메인보드 BIOS에서 CPU 가상화 지원(Intel VT-x / AMD AMD-V)이 꺼져 있기 때문입니다. PC 전원을 켜자마자 F2 또는 Del 키를 연타하여 BIOS 진입 후 Advanced/CPU Configuration 메뉴에서 Virtualization 설정을 Enabled로 변경해 주세요.
Q3: CMD나 PowerShell에서 docker를 입력하면 "'docker'은(는) 내부 또는 외부 명령으로 인식되지 않습니다"라고 나옵니다.
A: 시스템 PATH 환경변수 등록이 누락된 경우입니다. 시스템 환경 변수 편집 -> Path 항목에 C:\Program Files\Docker\Docker\resources\bin 경로를 수동으로 추가하고 터미널을 다시 실행하세요.
