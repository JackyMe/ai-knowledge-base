Antigravity 使用指南

区分桌面、CLI、IDE 与 SDK，按任务选择入口，再检查权限与输出。

01

先区分使用形态

桌面端用于组织项目与任务；CLI 适合终端和 SSH；IDE 集成编辑环境；SDK 用于程序化构建代理。各形态的版本、设置与快捷键不应混用。

www.antigravity.google · home · 2026-09-09

02

安装与登录

macOS / Linux 使用官方原生安装器。运行 agy 后按登录流程操作；SSH 场景可在本地浏览器完成授权。安装后先确认可执行文件位置与版本。

curl -fsSL https://antigravity.google/cli/install.sh | bash
command -v agy
agy --version
agy

www.antigravity.google · install · 2026-09-09

03

CLI 常用操作

在会话内输入 / 查看当前可用命令。常用入口包括 /help、/diff、/resume、/permissions、/context 和 /usage。代理内部的文件编辑工具不是可直接在终端运行的 agy 子命令。

www.antigravity.google · reference · 2026-09-09

04

设置与扩展

通过 /config 检查 CLI 设置，通过 /mcp 查看工具连接。规则、Skills、Hooks 和插件承担不同职责；配置文件位置和格式应以对应形态的文档为准，不要把自拟 YAML 当作内置权限规则。

www.antigravity.google · settings · 2026-09-09

05

后台任务与非交互运行

长任务先明确产物、写入范围和验收命令，再通过 /agents 与 /tasks 查看状态。脚本调用使用 -p；不要把工具内部状态名或示意流程写成不存在的终端接口。

agy -p "Summarize this repository without changing files" --output-format json

www.antigravity.google · headless · 2026-09-09

06

权限、沙箱与额度

检查实际启用的终端沙箱和工具权限；不要假定所有平台默认断网。提示词或规则文件不能替代执行权限。查看 /usage 的模型额度、/context 的上下文占用，分别处理两类限制。

www.antigravity.google · permissions · 2026-09-09

07

按症状排查

命令找不到：检查 PATH 与安装目录。登录失败：保留错误码，核对账号、网络与系统时间。工具被拒绝：查看当前权限原因。输出不可靠：缩小任务，附原始证据，并要求可验证结果。不要直接清空配置或跳过权限。

www.antigravity.google · troubleshooting · 2026-09-09

08

一个可验证的任务流程

示例：先读取认证模块并说明现状，列出具体修改与风险，再实施范围内的改动。运行项目已有测试，检查 diff，汇报通过与未验证项。涉及发布、付费或对外发送消息时，单独明确授权。
