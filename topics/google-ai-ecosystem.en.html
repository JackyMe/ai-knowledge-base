01

Choose tools by task

Use Gemini API for programmatic calls, NotebookLM for source-based research, Canvas for prototypes, and Antigravity for code work. Start with one tool; combine only when needed.

02

API access and model selection

Check model IDs, context limits, regions, and quotas for your platform. Do not assume a universal 2M window. Set your API key and available model ID before this GenerateContent example.

import os
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
response = client.models.generate_content(
    model=os.environ["GEMINI_MODEL"],
    contents="Summarize the supplied requirements and list open questions.",
)
print(response.text)

Caching: measure hits and total cost

Interactions supports implicit caching; explicit cache objects use GenerateContent. Pass a cache name in the cache field, not as the model. Measure total costs rather than promising a fixed saving.

04

Structured output and validation

Use a supported JSON Schema and validate values and business rules. Valid JSON does not guarantee correct facts. Handle refusals, truncation, empty results, and request failures; APIs use different configuration shapes.

05

NotebookLM: citations and verification

Collect relevant sources and ask focused questions. Verify cited passages, dates, and conditions. Citations do not guarantee accuracy, and source, file, and generation limits depend on the plan.

support.google.com · notebooklm · 2026-09-09

06

Prepare useful sources

Keep headings, provenance, versions, and code paths. Exclude dependencies, build output, duplicates, and credentials. Check supported formats and data policies; verify OCR for scanned documents.

07

Audio overviews and learning

Use audio overviews for orientation, not as replacements for sources. Specify audience and scope, then verify names, numbers, and attribution against the original material.
