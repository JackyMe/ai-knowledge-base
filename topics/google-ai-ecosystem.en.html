Python SDK Practical Example

Below is a complete google-genai SDK workflow: initializing the client, creating a secure streaming conversation, and efficient reuse based on Context Cache.

from google import genai
from google.genai import types
import datetime

client = genai.Client()

def select_model(token_budget: int, latency_ms: int):
    if token_budget > 1_000_000:
        return "gemini-2.0-pro"
    if latency_ms < 150:
        return "gemini-2.0-flash"
    return "gemini-2.0-flash-lite"

cache = client.caches.create(
    model=select_model(token_budget=2_000_000, latency_ms=200),
    config=types.CreateCachedContentConfig(
        contents=[types.Content(role="user", parts=[types.Part.from_uri(file_uri="gs://my-bucket/large_spec.txt", mime_type="text/plain")])],
        system_instruction="You are a senior system architect, please answer based on the provided documents.",
        ttl=datetime.timedelta(minutes=30),
    ),
)

stream = client.models.generate_content(
    model=cache.name,
    contents="Please explain the high availability design principles of the system and give improvement suggestions.",
    config=types.GenerateContentConfig(
        response_mime_type="text/plain",
        temperature=0.2,
        candidate_count=1,
        stream=True,
    ),
)
for chunk in stream:
    print(chunk.text, end="")

client.caches.delete(name=cache.name)

1.2 Context Caching in Practice (90% Cost Reduction)

🔥 Hardcore Practice When you need to feed an entire company's private SDK documentation repository (assuming 1.5 million Tokens) to a large model, if you re-transmit these 1.5 million Tokens every time a user asks a question, not only will API costs explode instantly, but the time-to-first-byte will also exceed 30 seconds. Context Caching is the absolute watershed separating senior from novice developers.

Physical Principles of KV Cache

When processing prefix text, large models need to perform massive matrix multiplications to generate Key-Value (KV) tensors. The essence of Context Caching is to freeze these calculated KV tensors and resident them in Google's GPU memory clusters. In the next request, it directly bypasses the attention calculation of these 1.5 million Tokens and reuses them directly from memory.

Python SDK: Explicit Caching Lifecycle Management

The following code demonstrates the complete lifecycle of enterprise-level caching: creation, invocation, querying for renewal, and destruction. Be sure to introduce TTL monitoring in production environments.

💻 Note: Explicit Caching Billing Rules

You need to pay for cache creation (billed as one-time input) and cache storage (billed hourly). However, for subsequent cache hit requests, the cost is only about one-tenth of the original price!

import datetime
from google import genai
from google.genai import types

client = genai.Client()

# 1. Initialize massive corpus (e.g., million-word architecture document, 2-hour audio file)
document_uri = "gs://your-bucket/massive_architecture_repo.txt"

# 2. Create Context Cache physically
# Set TTL (Time To Live) to 60 minutes
print("📦 Freezing context to GPU cluster...")
cache = client.caches.create(
    model='gemini-2.0-flash',
    config=types.CreateCachedContentConfig(
        contents=[
            types.Content(
                role="user",
                parts=[
                    types.Part.from_uri(file_uri=document_uri, mime_type="text/plain")
                ]
            )
        ],
        system_instruction="You are a senior kernel R&D expert. All following questions should be answered based on this source code repository.",
        ttl=datetime.timedelta(minutes=60),
    )
)

print(f"✅ Cache created successfully! Cache ID: {cache.name}")

# 3. Use cache for ultra-fast dialogue
response = client.models.generate_content(
    model='gemini-2.0-flash',
    contents='Please summarize the core design patterns regarding the database Connection Pool in this source code repository.',
    config=types.GenerateContentConfig(
        cached_content=cache.name, # ⚡️ Core parameter: mount cache handle
    )
)
print(f"🤖 Ultra-fast response:\n{response.text}")

# 4. [Advanced Technique] Cache Renewal (TTL Extension)
# If monitoring shows high-frequency calls at 50 minutes, the program should automatically initiate renewal
updated_cache = client.caches.update(
    name=cache.name,
    config=types.UpdateCachedContentConfig(
        ttl=datetime.timedelta(hours=2) # Forcibly extend life by 2 hours
    )
)

# 5. Graceful exit, release GPU memory and stop billing
client.caches.delete(name=cache.name)
print("🗑️ Cache physically destroyed.")

1.3 Structured Outputs Strong Typing Constraints

⚡ Strong Consensus This is the most important feature that takes AI from a "chat toy" to an "industrial-grade gear". Traditional developers like to beg bitterly in the Prompt: "Please, please output a valid JSON, the field name must be user_name, please do not wrap it with Markdown backticks, thank you!".

The result is often that after the model succeeds 99 times, on the 100th time it suddenly adds a sentence to you like "Here is the JSON you wanted:\n ```json ...", causing the JSON parser of the online microservice to crash and throw a 500 error on the spot.

Implementing Physical-level Constraints using Pydantic

The Structured Outputs provided by Gemini is not a simple Prompt hint, but rather a **probability tree pruning** performed at the Sampling Layer when the model generates the next Token. If the model attempts to generate a character that does not conform to the JSON structure you specified, the probability of that character will be physically zeroed! This achieves a 100% guarantee of Schema legality.

❌ Anti-pattern: Begging Prompt Writing in Prompt: "Please return a JSON, it must have name (string) and age (integer)".
This writing style is extremely fragile. Once the model hallucinates, it will break the structure.
✅ Best Practice: AST Definition Driven Use Pydantic to define a strict class structure, pass it to the model as response_schema, and replace language begging with a strong typing contract.

Complex Nested Business Practice: AI Fully Automatic Web Scraping Parser

Below is a crawler cleaning script that can be directly used in a production environment. No matter how chaotic the input web page source code is, the output will always be a perfect JSON tree.

from pydantic import BaseModel, Field
from google import genai
from google.genai import types

client = genai.Client()

# 1. Use Pydantic to define extremely strict nested structures
class ProductVariant(BaseModel):
    color: str = Field(description="Product color, e.g., 'Space Gray', 'Midnight Black'")
    price_usd: float = Field(description="Price, must be converted to a pure numeric float, stripping currency symbols")
    in_stock: bool = Field(description="Whether it is in stock")

class ProductInfo(BaseModel):
    product_name: str
    brand: str
    variants: list[ProductVariant] = Field(description="List of all variants of this product")
    customer_rating: float | None = Field(description="If there is no rating, strictly set to null")

# 2. Simulate chaotic input data
messy_html = """
<div> 
  <h1>SuperPhone 15 Pro Max (Apple)</h1>
  <span>Color: Space Gray - $1099 (Out of stock!)</span><br>
  <span>Color: Silver - $1049 (Available)</span>
  <!-- No rating available on this page -->
</div>
"""

# 3. Enable Structured Outputs mandatory constraints
response = client.models.generate_content(
    model='gemini-2.0-flash',
    contents=f"Please extract product information accurately from the following chaotic HTML:\n{messy_html}",
    config=types.GenerateContentConfig(
        response_mime_type="application/json",
        response_schema=ProductInfo, # ⚡️ Core parameter: directly inject Pydantic Class
        temperature=0.1, # Lower randomness to ensure extraction certainty
    ),
)

# 4. The response.text here will 100% be a valid JSON string
import json
print(json.dumps(json.loads(response.text), indent=2, ensure_ascii=False))

# Expected output:

2.2 Perfect Feeding Posture for Long Text and Massive Codebases

🔥 Hardcore Practice NotebookLM is an excellent brain, but the quality of "food" many developers feed it is too poor. Directly throwing a .zip containing hundreds of thousands of lines of node_modules or dist compilation products to the model will cause severe context pollution, and the model will be drowned in garbage code.

The approach of high-level players is: before feeding, use Python's AST (Abstract Syntax Tree) or regex filtering scripts to perform "dimensionality reduction extraction" on the legacy codebase.

Heavyweight AST Codebase Flattening Script (Repository Flattening)

The following Python script is a must-have tool for senior R&D teams. It not only automatically excludes useless files, but also automatically extracts the function definition graph, and finally synthesizes an extremely clearly structured .txt for the large model to swallow.

import os
import ast
from pathlib import Path

# Define garbage directories and file types that should absolutely not be fed to AI
IGNORE_DIRS = {'.git', 'node_modules', 'dist', 'build', '__pycache__', '.venv', 'logs'}
IGNORE_EXTS = {'.pyc', '.png', '.jpg', '.pdf', '.zip', '.tar.gz', '.log'}

def parse_python_ast(file_path):
    """
    [Advanced Technique] For Python files, we don't just feed the code, we also extract its syntax tree structure,
    allowing the large model to see at a glance what core Classes and Defs are in the file, significantly improving the success rate of correlated reasoning!
    """
    try:
        with open(file_path, "r", encoding="utf-8") as f:
            content = f.read()
        tree = ast.parse(content)
        classes = [node.name for node in ast.walk(tree) if isinstance(node, ast.ClassDef)]
        functions = [node.name for node in ast.walk(tree) if isinstance(node, ast.FunctionDef)]
        return f"AST Structure Summary - Classes: {classes}, Functions: {functions}\n{content}"
    except Exception as e:
        return f"Parsing failed: {e}"

def flatten_repo_to_document(repo_path: str, output_file: str):
    """
    Flatten the entire massive codebase into a Markdown-style knowledge base document
    """
    with open(output_file, 'w', encoding='utf-8') as out_f:
        out_f.write("# Massive Codebase Panoramic Scan Dossier\n\n")
        
        for root, dirs, files in os.walk(repo_path):
            # Filter garbage directories
            dirs[:] = [d for d in dirs if d not in IGNORE_DIRS]
            
            for file in files:
                ext = Path(file).suffix
                if ext in IGNORE_EXTS:
                    continue
                    
                file_path = os.path.join(root, file)
                rel_path = os.path.relpath(file_path, repo_path)
                
                out_f.write(f"\n{'='*60}\n")
                out_f.write(f"📁 File path: {rel_path}\n")
                out_f.write(f"{'='*60}\n")
                
                # Special treatment for Python files
                if ext == '.py':
                    content = parse_python_ast(file_path)
                else:
                    # For other types (e.g., JS/TS/Go), read content directly
                    try:
                        with open(file_path, 'r', encoding='utf-8') as f:
                            content = f.read()
                    except UnicodeDecodeError:
                        content = "[Binary or non-UTF-8 file, skipped]"
                        
                out_f.write(f"```\n{content}\n```\n\n")
                print(f"✅ Extracted: {rel_path}")

# Execute flattening operation
flatten_repo_to_document("./my_legacy_enterprise_repo", "knowledge_base_ready_for_NotebookLM.txt")

Python SDK: Compliance Parameters and Negative Prompt Tuning

The following code demonstrates how to call Imagen 3 on the server side and introduce the person_generation control parameter, which is very important in enterprise development. In many countries, automatically generating real human faces may involve copyright and legal disputes, and we need to apply hard restrictions at the API level.

from google import genai
from google.genai import types

client = genai.Client()

# First step: Use Gemini Flash to "expand" the user's rough input into a professional prompt
user_input = "A cyberpunk cat typing on a keyboard"
prompt_enhancement = client.models.generate_content(
    model='gemini-2.0-flash',
    contents=f"Please convert the following content into a professional Midjourney/Imagen image generation prompt, adding lighting, lens, and material descriptions: {user_input}",
)
professional_prompt = prompt_enhancement.text

# Second step: Call Imagen 3 to generate
print("🎨 Calling Imagen 3 engine to render...")
result = client.models.generate_images(
    model='imagen-3.0-generate-002',
    prompt=professional_prompt,
    config=types.GenerateImagesConfig(
        number_of_images=1, # Generation quantity
        aspect_ratio="16:9", # Control aspect ratio, optional "1:1", "3:4", "4:3", "9:16"
        output_mime_type="image/jpeg",
        # ⚡️ Core parameter 1: Negative prompt, exclude low-quality features
        negative_prompt="blurry, deformed, low resolution, watermark, bad anatomy",
        # ⚡️ Core parameter 2: Legal compliance control
        # DONT_ALLOW: Absolutely forbid generating human faces
        # ALLOW_ADULT: Allow adults (may require special permissions)
        person_generation="DONT_ALLOW" 
    )
)

# 3. Save the generated images

⚡ Strong Consensus When you grant AI permission to run terminal commands (e.g., BypassSandbox: true), if the AI experiences severe hallucination, it might execute rm -rf / in your system or accidentally delete important database files. All run_command or write_to_file requests that the Agent attempts to execute must penetrate the middleware layer before reaching the physical operating system:

Hardware-level Interceptor Source Code (DevSecOps)

The following code demonstrates how to use an interceptor to completely block any dangerous commands involving rm or modifying the root directory.

from antigravity.sdk import AntigravityApp, ToolCallRequest
import re

app = AntigravityApp()

# Define regex blacklist for dangerous commands
DANGEROUS_PATTERNS = [
    re.compile(r"rm\s+-r"),     # Recursive deletion
    re.compile(r"rm\s+/"),      # Delete root directory
    re.compile(r"chmod\s+-R\s+777"), # Extremely dangerous privilege escalation
    re.compile(r"DROP\s+DATABASE", re.IGNORECASE)
]

@app.middleware("run_command")
async def secure_command_interceptor(request: ToolCallRequest, next_handler):
    """
    When Agent attempts to call run_command, it enters this onion model.
    """
    cmd = request.arguments.get("CommandLine", "")
    
    # 1. Intercept dangerous operations
    for pattern in DANGEROUS_PATTERNS:
        if pattern.search(cmd):
            print(f"🚨 [Security Interception] Found dangerous command: {cmd}")
            # Throw error directly to Agent and let it reflect on its own
            return {
                "error": True,
                "message": "SECURITY_VIOLATION: You have no right to execute destructive commands. Please use a safe way to complete the task."
            }
            
    # 2. Require manual approval for operations needing network permissions
    if request.arguments.get("BypassSandbox") == True:
        print(f"⚠️ Agent requests jailbreak execution: {cmd}")
        user_input = input("Allow? (y/N): ")
        if user_input.lower() != 'y':
            return {"error": True, "message": "User rejected the bypass request."}
            
    # 3. Security check passed, hand over to underlying system for execution
    return await next_handler(request)

if __name__ == "__main__":
    app.start()

5.2 Disaster Scene Replay: 4 Major Bloody Anti-patterns Absolutely Not to Do

🔥 Hardcore Practice When many beginners first come into contact with these powerful tools, incorrect postures lead to system crashes, wasted time, and even security incidents. The following are 4 major "disaster scenes" we have summarized in countless practical battles, please be sure to carve them into your DNA.

❌ Anti-pattern 1: Letting AI "Rewrite the whole project" (Missing Strangler Fig Pattern)

💥 Disaster Scene Replay A novice enters in the Antigravity terminal: "Upgrade the entire `src` folder from Vue 2 to React 18, and refactor with TypeScript".

Root Cause Analysis: Large models extremely lack a "network dependency big picture". It will frantically modify 100 files at the same time, exhaust Tokens halfway or generate cascading errors, fall into an infinite loop, and ultimately leave you with ruins that can never be compiled.
✅ Best Practice: Progressive Strangler Fig Pattern Break the tasks down to the function level in implementation_plan.md. "Step 1: Only migrate `src/utils/format.js` to TS and add unit tests." After confirming it runs successfully and Committing, then proceed to the next one.

❌ Anti-pattern 2: Blindly Trusting Answers Without Superscript Citations

💥 Disaster Scene Replay Using a normal Web chat box to let Gemini read the company's core authentication source code, it smoothly tells you: "Call AuthManager.verifyToken() to decrypt". You take it as true and copy it into the codebase.

Root Cause Analysis: The verifyToken function does not exist in the company's source code at all! That is a high-frequency writing style the model memorized from an open-source JWT library, this is a typical "common sense override hallucination".
✅ Best Practice: Strongly Rely on NotebookLM Superscripts Any architecture-level questions involving "reading private massive long texts/source codes" must be asked in NotebookLM, and strictly demand: "All conclusions must be accompanied by original source superscript citations like [1][2], and for unmentioned content, you must answer don't know!"

❌ Anti-pattern 3: Infinite Trial and Error, Never Physically Archiving (Git Abuse)

💥 Disaster Scene Replay Letting the Agent fix a Bug in the IDE, it goes back and forth modifying 50 files. You think it's finally fine, but upon running, you find it deleted the core routing table during its 20th modification. You press Ctrl+Z trying to undo, only to find the history has been completely washed away and messed up by thousands of lines of changes.

Root Cause Analysis: Treating AI as a god that makes no mistakes. A whole day's work goes down the drain, resulting in a mental breakdown.
✅ Best Practice: High-frequency Atomic Commits Every time the Agent successfully solves a sub-task (e.g., finishes writing an API interface and passes testing), immediately git commit -m "feat: agent finished login API". Turn Git into a shared "progress save point" between you and the Agent. Once it starts talking nonsense, simply git reset --hard.

❌ Anti-pattern 4: Begging Prompt

💥 Disaster Scene Replay Writing in the Prompt: "Please, please output a valid JSON, the field name must be user_name, please do not wrap it with Markdown backticks, if you do my system will crash, please!"

Root Cause Analysis: This is a manifestation of lacking engineering literacy. Even if it succeeds 99 times, due to the randomness of LLM sampling, on the 100th time it will still add a ```json for you, causing massive 500 errors in online microservices.
✅ Best Practice: Physical API Constraints (Structured Outputs) Always use response_schema. Replace natural language begging with strict Pydantic Schema definitions, achieving a 100% physical blockade of legality at the Sampling Layer when the model generates the next Token.
