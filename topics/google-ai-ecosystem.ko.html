01

작업별 도구 선택

프로그램 호출은 Gemini API, 자료 기반 연구는 NotebookLM, 시제품은 Canvas, 코드 작업은 Antigravity를 사용합니다. 필요한 경우에만 도구를 연결하세요.

02

API 연결 및 모델 선택

모델 ID, 컨텍스트 크기, 지역, 할당량을 플랫폼별로 확인하세요. 모두 2M이라고 가정하지 마세요. 예제 실행 전에 API 키와 모델 ID를 설정하세요.

import os
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
response = client.models.generate_content(
    model=os.environ["GEMINI_MODEL"],
    contents="Summarize the supplied requirements and list open questions.",
)
print(response.text)
