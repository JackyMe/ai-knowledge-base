pen.dev 문서
한국어 가이드

pen.dev는 코드 에디터(VS Code / Cursor)에 직접 내장된 강력한 벡터 디자인 도구입니다. 캔버스에서 디자인하고 즉시 코드로 변환. 공식 docs.pencil.dev의 최신 사양(pen.dev 리브랜딩, 신규 CLI / MCP 도구 체계 반영)을 담은 완성형 레퍼런스입니다.

개요

pen.dev란 무엇인가?

원문: pen.dev Documentation (Home)

pen.dev는 개발 환경(IDE) 내부에 직접 통합된 벡터 디자인 툴입니다. 별도의 디자인 툴이나 브라우저 탭을 오갈 필요 없이, 코드와 동일한 작업 공간에서 UI를 직접 설계하고 편집할 수 있습니다.

왜 pen.dev인가? 디자인과 코드를 동일한 Git 저장소에 모아 양자 간의 괴리를 제거합니다. 캔버스에서 컴포넌트를 설계하고, Design Tokens를 코드와 동기화하며, AI 에이전트와 연계하여 UI 구현 속도를 획기적으로 높입니다.

퀵스타트

설치

원문: Installation

VS Code / Cursor의 확장 프로그램 패널에서 간편하게 설치합니다:

  1. 에디터 확장 탭에서 pen.dev (게시자: highagency.pencildev) 검색 후 설치.
  2. 상태 표시줄 왼쪽 하단의 Pencil 아이콘을 클릭하여 캔버스 기동.
  3. 첫 실행 시 이메일을 입력하여 활성화 완료.
퀵스타트

인증 및 활성화

원문: Authentication

입력한 이메일로 발송되는 6자리 인증 코드를 입력하면 즉시 로그인이 완료됩니다. 세션 정보는 로컬에 안전하게 저장됩니다.

퀵스타트

AI 통합 (MCP)

원문: AI Integration

pen.dev는 Model Context Protocol (MCP)을 통해 다양한 AI 코딩 에이전트(Claude Code, Cursor, Codex, OpenCode 등)와 매끄럽게 연결됩니다.

# Claude Code에서 MCP 연결 확인
/mcp

AI 에이전트는 캔버스 상의 요소 좌표와 Design Tokens를 직접 읽어 디자인을 코드로 변환하거나, 자연어 프롬프트를 바탕으로 새 화면을 캔버스 위에 직접 렌더링할 수 있습니다.

핵심 개념

.pen 파일

원문: .pen Files

.pen은 pen.dev의 네이티브 파일 형식입니다. 본질은 깔끔한 JSON 데이터이므로 Git을 통한 버전 관리, 커밋 Diff 비교, 브랜치 머지를 완벽하게 지원합니다.

핵심 개념

Design as Code (설계 즉 코드)

원문: Design as Code

  • 단일 저장소 관리: design.pen을 소스 코드와 동일한 Git 리포지토리에서 관리.
  • 브랜치와 PR 일원화: 기능 브랜치에서 UI 디자인과 소스 코드를 동시에 수정하고 하나의 PR로 코드 리뷰.
  • 동기화된 롤백: git revert 실행 시 코드와 디자인 시안이 함께 과거의 정상 시점으로 안전하게 롤백.
핵심 개념

pen.dev 인터페이스

원문: The Interface

  • 좌측 패널 (Layers / Libraries): 레이어 계층 구조, 프레임 목록, 임포트된 디자인 라이브러리.
  • 중앙 캔버스 (Infinite Canvas): 벡터 그래픽을 자유롭게 편집하는 무한 캔버스 영역.
  • 우측 인스펙터 (Inspector): 선택 노드의 속성 (좌표, 크기, 채우기, 선, 코너 라운딩, 그림자 이펙트, 변수 바인딩).
핵심 개념

변수 (Variables / Design Tokens)

원문: Variables

색상, 수치(여백 및 반경), 문자열을 Design Tokens로 정의하고 각 요소에 $color.primary 형태로 바인딩합니다. 토큰 값을 한곳에서 변경하면 캔버스 전체와 CSS 코드에 즉각 전파됩니다.

핵심 개념

컴포넌트 (Components)

원문: Components

재사용 가능한 UI 요소를 생성합니다. 마스터 컴포넌트를 수정하면 연결된 모든 인스턴스(참조 노드)에 변경 사항이 일괄 반영됩니다.

핵심 개념

슬롯 (Slots)

원문: Slots

컴포넌트 내부의 특정 영역을 동적으로 교체할 수 있도록 비워 둔 플레이스홀더입니다. 모달 창의 본문 영역이나 카드 컴포넌트의 미디어 영역 등에 활용됩니다.

핵심 개념

캔버스 상의 코드 (Code on Canvas / Script Nodes)

원문: Code on Canvas

JavaScript / TypeScript 스크립트를 작성하여 데이터 기반 차트나 복잡한 기하학적 도형을 캔버스 상에 프로그래밍 방식으로 직접 렌더링할 수 있습니다.

핵심 개념

디자인 라이브러리 (Design Libraries)

원문: Design Libraries

.lib.pen 포맷으로 저장된 공통 디자인 시스템을 여러 프로젝트 간에 공유하고 손쉽게 임포트하여 사용할 수 있습니다.

디자인 & 코드

디자인 ↔ 코드 동기화

원문: Design to Code

캔버스의 노드 구조로부터 Tailwind CSS, React, Vue, HTML/CSS 컴포넌트를 즉시 추출할 수 있습니다. 반대로 기존 소스 코드를 읽어 캔버스 상의 시각적 요소로 역재현하는 것도 가능합니다.

문제 해결

트러블슈팅

원문: Troubleshooting

  • MCP 연결 실패: claude CLI 로그인 상태를 점검하고 에디터를 재시작.
  • 캔버스 렌더링 불가: VS Code의 GPU 가속 설정 확인.
  • 수정 내용 유실: 현재 자동 저장 기능이 없으므로 반드시 Cmd/Ctrl + S로 수동 저장 습관화.

pen.dev CLI & MCP 도구 체계

원문: pen.dev CLI

CLI(@pen.dev/cli)를 통한 헤드리스 자동화 실행 및 AI 에이전트가 호출하는 MCP 도구 목록:

MCP 도구명기능 설명
execute노드 추가·수정·삭제·이동·교체, 변수 읽기 및 쓰기 (GetVariables / SetVariables)
get_app_state문서 전체의 노드 구조 및 메타데이터 조회
get_screenshot지정 노드를 PNG 이미지로 렌더링 캡처
export_nodes노드를 PNG / JPEG / WebP / PDF 등으로 익스포트
get_guidelines디자인 가이드라인 및 스타일 규약 조회
